# Better Enrollment Docs

Documentation and landing site for [`@octopi-ai/better-enrollment`](https://github.com/OctopiAI/better-enrollment), built with Next.js, Fumadocs, shadcn/ui, and Tailwind CSS.

## Development

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000. Docs content lives in `content/docs` as MDX; page order is set in `content/docs/meta.json`.

## Build

```bash
pnpm build
pnpm start
```
